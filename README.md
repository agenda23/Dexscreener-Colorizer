# Dexscreener Colorizer 🚀

**Dexscreenerの取引履歴を金額別にリアルタイム色分けし、大口の動きを可視化するトレーダー向け補助ツール**

Dexscreener標準のアイコン（ウォレット属性）に惑わされず、「いま、いくらの買いが入ったか」を直感的に判別できるようにします。

---

## ✨ 主な機能

- **金額ベースの5段階判定**: $10k超のWhaleから$10未満のPlanktonまで、金額のみで厳密に色分け。
- **リアルタイム同期**: 新しく流れてくる取引も、ミリ秒単位で検知して自動で色付け。
- **スクロールズレ完全防止**: 履歴を遡っても、DOMの再描画を監視しているため色がズレません。
- **完全無料・安全**: APIキー不要、個人情報の送信なし。ブラウザ上で完結する軽量設計。

## 🚀 導入方法（わずか3ステップ）

PCに詳しくない方でも簡単に導入できます。

1. **配布ページにアクセス**
   [👉 Dexscreener Colorizer インストールページ](https://agenda23.github.io/Dexscreener-Colorizer/)

2. **ブックマーク登録**
   ページ上の緑色のボタンを、ブラウザの**ブックマークバーへドラッグ＆ドロップ**して保存します。

3. **Dexscreenerで起動**
   Dexscreenerのトークンページで「Transactions」タブを開き、保存したブックマークをクリックしてください。「起動しました！」と通知が出れば完了です。

---


## ⚠️ 注意事項

- **環境**: PC版 **Google Chrome** を推奨します。スマートフォンアプリ版では動作しません。
- **仕様**: ページをリロードしたり、別のトークンページへ移動した場合は元の表示に戻ります。その際は、**再度ブックマークをクリック**してください。
- **判定について**: サイト独自の動物アイコン表示とは基準が異なります。本ツールは「現在の取引金額」を最優先して色分けします。
- **Transactionsタブ限定**: 履歴（Transactions）タブのみに対応しています。Top Traders等の他タブでは動作しません。
