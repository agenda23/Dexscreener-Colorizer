# 開発ウォークスルー: Dexscreener Colorizer 配布ページ

## プロジェクト概要
Dexscreener の取引一覧を視認しやすくするためのブックマークレット配布ページを作成しました。
ターゲットユーザーは PC 操作に詳しくないトレーダーも含んでおり、直感的な「ドラッグ＆ドロップ」による登録体験を重視しています。

## デザインのこだわり
システムプロンプトの「Rich Aesthetics」に基づき、以下の点を強化しました。

1.  **モダンなダークモード**: `slate` と `zinc` を基調とした背景に、Dexscreener のイメージカラーに近い `emerald` をアクセントとして採用。
2.  **グラスモーフィズム**: メインの CTA エリア（ドラッグボタン）やセキュリティセクションに、すりガラスのような背景透かし効果を適用し、プレミアム感を演出。
3.  **ダイナミックな演出**:
    *   背景に微細なグリッドとグラデーションを配置。
    *   ボタンのホバーエフェクト（拡大、発光）。
    *   ドラッグを促すアニメーションアイコン。
4.  **タイポグラフィ**: 視認性の高い `Inter` と、見出し用に洗練された `Outfit` フォントを Google Fonts からインポート。

## 実装のポイント
*   **ブックマークレット埋め込み**: 最新の JavaScript コードを最小化し、`<a>` タグの `href` に `javascript:` プロトコルとして埋め込みました。
*   **ビフォーアフター画像**: AI（generate_image）を使用して、ツールの効果が一目でわかる比較画像を生成・配置しました。
*   **ランク解説**: 金額ごとの色分けルールを凡例として明示し、ユーザーが導入後のメリットを想起しやすくしました。
*   **注意事項・免責事項**: ユーザーが正しく安全にツールを利用できるよう、推奨環境や使い方のコツ、免責事項をまとめたセクションを追加しました。
*   **セキュリティの明文化**: 安心して利用できるよう、完全クライアントサイドであることを強調しました。

## 技術スタック
*   HTML5 (Semantic HTML)
*   Vanilla CSS (Modern CSS properties, Flexbox, CSS Variables)
*   JavaScript (Smooth Scroll, simple UI helpers)
*   Google Fonts (Inter, Outfit)
